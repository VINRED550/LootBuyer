# LootBuyer — скупщик ресурсов для Paper/Purpur

[English version](README.md)

![Меню скупщика](images/1-menu.png) ![Подсказка с ценой](images/2-tooltip.png)

**LootBuyer** — скупщик ресурсов для Paper и Purpur. Игроки открывают `/buyer` и продают добычу серверу. Цены меняются по таймеру, у каждого предмета свой лимит, донатеры получают больше, а админы видят, кто что продал.

## Возможности

- **Удобное меню.** У каждого предмета видно цену, изменение с прошлой смены цен (▲/▼ в процентах), сколько ещё можно продать и сколько есть у игрока.
- **Быстрая продажа.** ЛКМ — 1 шт., ПКМ — стак, Shift + клик — всё. Кнопка «Продать всё» и команда `/buyer sellall`.
- **Смена цен по таймеру.** Случайная цена в заданном диапазоне, объявление в чат.
- **Режим анархии.** При каждой смене цен можно скупать только случайный набор предметов (`items-per-rotation`).
- **Лимиты на игрока** сбрасываются при смене цен, так что фермы не сломают экономику.
- **Множители для донатеров.** Выдайте право `lootbuyer.multiplier.vip`, и игрок получит ×1,1 (настраивается).
- **История продаж для админов.** `/buyer history <игрок>` показывает каждую продажу с датой, предметом, количеством и суммой, плюс итог за период. Срок хранения задаётся в конфиге, историю можно выключить.
- **Защита.** Скупаются только обычные предметы: переименованные, зачарованные и кастомные вещи других плагинов не принимаются. Броня и вторая рука не продаются, а вытащить предмет из меню нельзя.
- **Сохранение.** Цены и лимиты переживают перезапуск сервера.
- **Работает на разных версиях.** Paper и Purpur от 1.16.5 до 26.x. Предметы, которых нет в вашей версии, пропускаются сами.
- **Языки.** Русский и английский, можно добавить свой. Названия предметов показываются на языке клиента игрока, если сервер это поддерживает. Все тексты настраиваются в формате MiniMessage (градиенты, HEX-цвета).
- Поддержка **PlaceholderAPI** и NPC **Citizens**.

## Требования

- Paper или Purpur **от 1.16.5 до 26.x** (форки Paper тоже подходят)
- Java 8 или новее, столько, сколько требует ваша версия сервера
- [Vault](https://www.spigotmc.org/resources/vault.34315/) и плагин экономики (EssentialsX, CMI и др.)
  - На 1.16.5 нужна EssentialsX **2.20.1**: новые версии EssentialsX 1.16.5 не поддерживают
- PlaceholderAPI — по желанию

Не поддерживаются: чистый Spigot, Folia.

## Команды и права

| Команда | Право | По умолчанию | Что делает |
|---|---|---|---|
| `/buyer` (`/lootbuyer`, `/skupka`, `/skup`) | `lootbuyer.use` | все | Открыть меню |
| `/buyer sellall` | `lootbuyer.sellall` | все | Продать всё подходящее |
| `/buyer history <игрок> [страница]` | `lootbuyer.history` | OP | История продаж игрока |
| `/buyer reload` | `lootbuyer.admin` | OP | Перезагрузить конфиг и тексты |
| `/buyer rotate` | `lootbuyer.admin` | OP | Сменить цены прямо сейчас |
| `/buyer open <игрок>` | `lootbuyer.admin` | OP | Открыть меню игроку (для NPC и меню) |
| — | `lootbuyer.bypasslimit` | никто | Продавать без лимитов |
| — | `lootbuyer.multiplier.<название>` | никто | Множитель цены из `config.yml` |

## История продаж

```
Скупщик » Продажи Steve за 7 дн.: 328 шт. на 10 593,6 $
 26.10 00:41 64 × Алмаз за 7 193,6 $
 26.10 00:41 128 × Железный слиток за 1 292,8 $
 ...
Страница 1/3. Дальше: /buyer history Steve 2
```

```yaml
history:
  enabled: true        # false — выключить
  keep-days: 7         # старые записи удаляются сами
  page-size: 10
  date-format: "dd.MM HH:mm"
```

## Плейсхолдеры

| Плейсхолдер | Значение |
|---|---|
| `%lootbuyer_next%` | Время до смены цен, например `12 мин 05 сек` |
| `%lootbuyer_next_seconds%` | То же в секундах |
| `%lootbuyer_price_<id>%` | Текущая цена за 1 шт., например `%lootbuyer_price_diamond%` |
| `%lootbuyer_active_<id>%` | `true`, если предмет сейчас скупается |
| `%lootbuyer_left_<id>%` | Сколько игрок ещё может продать |

## Скупщик-NPC (Citizens)

```
/npc create Скупщик
/npc command add -p buyer
```

Или от имени консоли, без выдачи прав игрокам:

```
/npc command add lootbuyer open <p>
```

## Настройка предметов

```yaml
language: ru            # ru, en или свой lang/<код>.yml
rotation-minutes: 60
items-per-rotation: 0   # 0 — все предметы, 7 — случайные 7 при каждой смене
items:
  diamond: { material: DIAMOND, price: [90, 140], limit: 128 }
  bone:    { material: BONE,    price: 2,         limit: 0 }   # фиксированная цена, без лимита
```

После правок: `/buyer reload`. Если поменять диапазон цены, цена предмета сразу выберется заново.
